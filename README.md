# Website Jual Kos-Kosan — GitHub Pages

## Cara menggunakan

1. Upload `index.html`, `style.css`, dan `script.js` ke repository GitHub.
2. Edit nomor WhatsApp di `script.js`:
   `const nomorWhatsApp = "628123456789";`
3. Jika sudah punya foto properti, buat folder `images` lalu masukkan foto:
   - `utama.jpg`
   - `foto2.jpg`
   - `foto3.jpg`
   - `foto4.jpg`
   - `foto5.jpg`
4. Untuk menampilkan foto asli, bagian placeholder di `index.html` dapat diganti dengan tag `<img>`.
5. Aktifkan GitHub Pages melalui Settings → Pages → Deploy from branch → pilih `main` dan `/root`.

## Catatan
Harga, nomor WhatsApp, nama brand, foto, dan informasi lain dapat diedit langsung di `index.html` / `script.js`.
